# Appendix C – References

The model is general relativity, described as flowing space, and nearly every piece of it is already in the
literature. Two pages set out where it comes from.

- **[References](references.md)**: the papers, books and measurements the site rests on, grouped by topic, each with
  where on the site it is used.
- **[Prior Work](prior-work.md)**: each piece of the model against the published work found, and what, if anything,
  looks new.
